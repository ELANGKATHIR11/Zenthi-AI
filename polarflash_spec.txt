# PART II — FUNDAMENTAL MATHEMATICAL FOUNDATIONS

## 1. Shannon Rate-Distortion Theory

POLAR-FLASH must treat model compression as an information-theoretic optimization problem.

The objective is not simply to reduce the number of bits.

It is to minimize the information required to represent model parameters while maintaining acceptable functional accuracy.

Let:

- W = original model weights.
- W_hat = reconstructed quantized weights.
- R = average encoding rate in bits per weight.
- D = reconstruction distortion.

Define:

\[
D=\mathbb{E}\left[\|W-\hat W\|_2^2\right]
\]

For a distribution of weights, define the rate-distortion function:

\[
R(D)=\min_{p(\hat W|W):\mathbb E[d(W,\hat W)]\leq D}
I(W;\hat W)
\]

where I denotes mutual information.

For a scalar Gaussian source with variance sigma squared and squared-error distortion:

\[
R(D)=\frac12\log_2\left(\frac{\sigma^2}{D}\right)
\]

for the applicable distortion range.

This scalar result must not be incorrectly presented as the exact rate-distortion limit of an entire transformer.

For a vector Gaussian source with covariance matrix Sigma:

\[
R(D)=\frac12\sum_i
\max\left(0,\log_2\frac{\lambda_i}{\theta}\right)
\]

where lambda_i are covariance eigenvalues and theta is determined by the distortion constraint.

The compressor must optimize:

\[

\]

\[
\sum_l N_lR_l\leq B
\]

where:

- N_l is the parameter count of layer l.

- B is the total bit budget.

Use constrained optimization or Lagrangian methods.

A useful objective is:

\[
\mathcal L=
\sum_l \alpha_lD_l(R_l)
+\lambda\left(\sum_lN_lR_l-B\right)
\]

Here alpha_l represents layer sensitivity.

Do not optimize raw weight MSE alone. Also measure the impact on model outputs and language-model loss.

## 2. High-Dimensional Geometry and Gaussian Concentration

Implement orthogonal transforms to reduce outlier concentration and improve low-bit quantization.

For a weight vector:

\[
w\in\mathbb R^d
\]

Apply:

\[
z=Hw
\]

where H is an orthogonal Hadamard transform:

\[
H^TH=I
\]

For normalized Hadamard matrices:

\[
H_{ij}\in\left\{-\frac1{\sqrt d},
+\frac1{\sqrt d}\right\}
\]

An orthogonal transform preserves energy:

\[
\|Hw\|_2^2=\|w\|_2^2
\]

It also preserves pairwise Euclidean distances.

However, it does not guarantee independent Gaussian transformed coordinates.

### Gaussian shell concentration

For an ideal isotropic Gaussian vector:

\[
z\sim\mathcal N(0,\sigma^2I_d)
\]

The squared radius follows:

\[
\frac{\|z\|_2^2}{\sigma^2}\sim\chi_d^2
\]

Therefore:

\[
\mathbb E[\|z\|_2^2]=d\sigma^2
\]

\[
\operatorname{Var}(\|z\|_2^2)=2d\sigma^4
\]

The expected radius is approximately:

\[
R\approx\sigma\sqrt d
\]

for large d.

Implement numerical experiments to verify radial concentration on actual transformed model weights.

Do not assume all weight blocks have the same variance or radial distribution.

## 3. Recursive Polar Coordinate Quantization

Develop PolarQuant as an experimental vector quantization method.

For each pair:

\[
(x_1,x_2)
\]

calculate:

\[
r=\sqrt{x_1^2+x_2^2}
\]

\[
\theta=\operatorname{atan2}(x_2,x_1)
\]

Reconstruction:

\[
x_1=r\cos\theta
\]

\[
x_2=r\sin\theta
\]

For higher-dimensional blocks, recursively decompose subvector norms and angular coordinates.

For a d-dimensional vector, the polar representation consists of one radius and d-1 angular coordinates.

The implementation must correctly handle:

- Zero-radius blocks.
- Numerical underflow.
- Angle wrapping.
- Signed coordinates.
- Boundary quantization.
- Scale variation.
- Inverse reconstruction.

### Polar distortion

For a two-dimensional polar vector:

\[
x=r
\begin{bmatrix}
\cos\theta\\
\sin\theta
\end{bmatrix}
\]

and reconstructed parameters r_hat and theta_hat:

\[
\|x-\hat x\|_2^2
=
r^2+\hat r^2-2r\hat r
\cos(\theta-\hat\theta)
\]

For small errors:

\[
D\approx
(\Delta r)^2+r^2(\Delta\theta)^2
\]

This equation must guide adaptive precision allocation.

Angular precision should depend on radius, because the same angular error produces greater reconstruction error for larger radii.

## 5. Johnson-Lindenstrauss and QJL Residual Correction

Let:

\[
e=w-\hat w
\]

be the quantization residual.

Use a randomized projection:

\[
S\in\{-1,+1\}^{m\times d}
\]

For independent Rademacher entries:

\[
\mathbb E[S^TS]=mI
\]

Therefore, an inner-product estimator can be defined as:

\[
\widehat{\langle x,e\rangle}
=
\frac1m(Sx)^T(Se)
\]

and:

\[
\mathbb E[\widehat{\langle x,e\rangle}]
=
\langle x,e\rangle
\]

The full corrected estimate is:

\[
\widehat{\langle x,w\rangle}
=
\langle x,\hat w\rangle
+
\frac1m(Sx)^T(Se)
\]

### Required mathematical validation

For the stated unnormalized sign matrix:

\[
\operatorname{Var}(\hat q)
=
\frac1m
\sum_{i\neq j}x_ie_ix_je_j
\]

when the relevant random variables are independent and the matrix entries have the specified distribution.

Test this expression against Monte Carlo experiments.

Implement separate variants:

- Dense random projection.

- Packed binary projection.
- Hardware-specific XNOR/popcount estimation.

## 15. Discrete P-Step

Every K optimization steps, calculate sensitivity to code changes.

For a candidate code change:

\[
\Delta c_i=c_i'-c_i
\]

A first-order approximation is:

\[
\Delta\mathcal L
\approx
\nabla_{c_i}\mathcal L^T\Delta c_i
\]

A second-order approximation may be:

\[
\Delta\mathcal L
\approx
\nabla_{c_i}\mathcal L^T\Delta c_i
+
\frac12
\Delta c_i^TH_i\Delta c_i
\]

where H_i is a suitable Hessian or curvature approximation.

Use the first-order approximation for candidate ranking, but validate selected changes against the actual objective.
